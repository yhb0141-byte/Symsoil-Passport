# 共壤随身确认卡：第一版规则

成员身份、事项确认、任务承担、AI 授权与积分记账各有自己的记录。一次回复只作用于当时展示的具体内容和版本。

## 确认语义

| 场景 | 可选择的回复 | 产生的结果 |
| --- | --- | --- |
| 贡献积分 | 领取、需要修改、拒绝 | 只有领取已核定的贡献才入账 |
| 积分兑换 | 确认扣除、拒绝 | 只有确认扣除才完成扣分并占用库存 |
| 原单退回 | 确认领取退回积分、拒绝 | 只有明确领取才返还原交易的积分 |
| 工具借用 | 同意承担、需要修改、拒绝 | 只登记这次工具借用的承担 |
| 转述核对 | 表达准确、需要修改、仅保留原话、不允许转述 | 保存各自的许可范围，不合并成批准 |
| 小壤有限授权 | 正式批准、需要修改、拒绝 | 只有正式批准才生成这次执行的授权 |

被征询由发起记录表示；查看由查看事件表示。查看和无操作都没有签名批准回执。需要修改、原话许可、拒绝与正式批准使用同一签名强度，语义由明确的字段区分。

界面采用「阅读内容 → 选择回复 → 核对这份内容 → 长按 OK 两秒」。返回、切换页面、失去焦点或提前松手会取消正在进行的按住动作。浏览器长按只演示交互，实际工牌须用硬件按键触发签名。

## 版本规则

- 摘要覆盖社区、成员、事项类型、单据、版本和完整正文。
- 修改借用事项、转述稿或授权内容会产生新版本；已提交的旧回执保留为历史记录。
- 未提交的旧版本无法产生新确认；旧版授权停止后续执行。已完成的行动不会因改版自动撤回。
- 积分单据不能改写金额，错误单据需取消或另开新单。已发生的积分变动通过关联原交易的退回记录处理。
- 每次待确认挑战有效期为两分钟，过期后须重新征询，不自动补填同意。

## 积分规则

第一版记录社区贡献与资源兑换，不提供人民币充值、现金提现、个人间转账或跨社区清算。

核定人每笔可核定 1–100 积分，每日累计核定上限 500 积分，按北京时间切日。即使成员尚未领取，已核定单据也占用当日额度。成员和 NFC 终端没有发行权限。目录固定价格由服务端给出，终端不能提交任意扣分金额。

积分流水包括起始、入账、兑换和退回四类。试用模式起始 100 积分，普通模式起始 0。余额不得为负；余额、流水、确认回执、设备计数器与库存一起提交或一起回滚。同一单据只记账一次，重试不再增加或扣除。

退款路径是「未交付的原扣分记录 → 核定人发起整笔退回 → 原成员明确领取」。原单可退回一次，库存同时恢复；已发起退回的单据不能登记交付。当前不支持部分退回或交付后的争议退款。

积分不能购买治理权限、表达权或基本服务。成员可以办理兑换而不答复其他议题，拒绝转述或 AI 授权也不会扣分。

## 小壤执行范围

当前执行器只更新本地数据库里的 `garden-roster` 排班。授权绑定精确文本、执行者 `xiaorang`、资源、动作、最多一次和批准后 24 小时期限。其他文本、其他资源、其他执行者或第二次独立执行会被拒绝。

成员可撤销未使用的授权。已使用的授权保留记录；重复相同执行单号只返回已完成结果。修改授权事项会停用旧版授权。此版本没有调用外部大模型、发送消息或委托其他代理。

## 下一阶段

真实工牌的可信显示和硬件按键签名、多人入会与换机流程、USB 或专用 NFC 终端、正式设备信任与恢复机制，是进入社区试点前的下一批工作。可离线验证的签发方授权封装和跨终端撤销传播尚未实现。
