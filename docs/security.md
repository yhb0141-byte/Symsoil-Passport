# 信任与实现边界

此版本用于本地开发、流程验证和硬件接入准备。它实现了可核验的登记设备回复与事务账本，尚未完成正式社区部署的身份、设备与运维体系。

## 已有约束

- 成员、核定人、兑换终端和执行者分别持有随机 Bearer 凭证；成员只能读取或回复自己的事项。
- 核定人签发贡献，成员明确领取。终端只能兑换固定目录内容；NFC 标签不能发行积分。
- 设备首次登记后不能被另一把公钥静默覆盖。换机前由核定人停用旧设备；旧卡、成员访问入口、待回复事项与未使用授权同时失效。核定人核对持有人后再签发新入口，避免旧凭证重新登记设备。
- 回复绑定完整正文摘要、版本、社区、成员、设备、一次性挑战、有效期、明确语义与计数器。
- SQLite 使用 `BEGIN IMMEDIATE`、唯一单据约束、WAL、外键和同步写入。积分、库存、回执和设备计数器一起提交或回滚。
- 流水和回执有禁止 UPDATE/DELETE 的数据库触发器。退回保留原扣分记录，不能通过删账恢复余额。
- 执行入口核验精确内容、资源、执行者、到期时间、撤销状态与次数；受限动作和次数消费在同一事务完成。
- HTTP 服务校验来源与 Host，不提供跨站读写；采用同源脚本 CSP，访问凭证仅在当前页面内存中使用。
- 写请求先校验凭证，接收完正文后在同一 SQLite 写事务里再次核验凭证。上传期间发生的撤销不能通过先前身份快照绕过；业务事务嵌套使用保存点，失败仍完整回滚。

## 物理确认的边界

按键能证明受信任设备进行了动作。要把动作归属本人，还需要入会与设备交接、失物停用、必要时 PIN 解锁、可信显示和防固件篡改。长按、双击或 NFC UID 本身都不等于不可伪造的本人授权。

当前浏览器私钥不可直接导出，但同源脚本或被控制的浏览器仍可调用签名；页面里的两秒长按不是密码学约束。未对浏览器、恶意管理员、设备持有者或数据库所有者提供硬件安全承诺。真实工牌须由固件守住「完整内容显示 + 明确选择 + 物理动作 → 签名」的边界。

成员访问凭证不是实名认证。运营界面提供多人登记、独立凭证、撤销和换机；首次设备登记与恢复仍依赖运营者把凭证发给正确的人。当前没有设备远程证明或 PIN，也不能用浏览器密钥代替在地身份核验。

## 断网与撤销

不连接互联网时，本机或社区局域网内的服务仍可运行。服务不可达时不能扣分，界面不会从标签上的数字推断可用余额，也不会先离线扣分再补账。

授权撤销在同一数据库执行端检查。完全隔离的验证方无法立即知道新的撤销；短有效期只能限制旧权限的持续时间，不能实现即时撤销。当前没有签发方签名的跨社区授权封装、可信时钟、撤销广播或离线卡钱包。

导出文件可以核验所提供公钥下的历史回复签名和流水算术，不证明签发方可信、真实持有人、导出完整性或授权仍未撤销。授权表本身没有独立的签发方签名，不能把导出 JSON 当成跨组织可接受的通行签证。

## 数据与恢复

NFC 只保存随机账户引用。标签可能被复制，读取者也可能关联多次使用；标签上的引用不是秘密或扣分权限。遗失后须停用旧入口，并重写新入口。复制标签会让事项被发送给原成员，但无法凭标签单独提交有效的扣分签名。

访问凭证文件权限为 0600；数据库和个人导出不是加密保险库。服务端磁盘读取权限、备份访问和终端物理管理仍由部署者负责。数据库触发器不会阻止拥有文件写权限的人替换整个数据库；要取得外部可证明的审计，后续需签名检查点或独立见证。

浏览器 IndexedDB 除不可导出的设备密钥外，还保存结果待核对的完整事项与签名。凭证原文不保存在其中；事项正文也未另做磁盘加密。退出页面不会删除尚未核对的签名，重新进入本人成员会话后可恢复。设备内的并发占位和计数器在同一 IndexedDB 事务更新，避免多个标签页覆盖密钥或同时签发不同回复。

新增访问凭证有有效期并支持在线撤销，数据库仅保存哈希，签发时仅显示一次原文。初始本机凭证来自 `access.json`，无自动到期，用于引导设置；可签发替代入口后撤销旧入口，旧凭证不会因服务重启恢复。文件读取权限仍须保护。撤销保护防止当下的最后一个有效核定人入口被删除，但到期后的恢复仍需本机运营者保管引导配置。

设备遗失时停止之后的旧设备签名，撤销该成员入口和未使用的小壤授权。已发生的积分交易、已执行行动与历史同意保留；停用设备不能撤回已交付的资源。

换机步骤：保管好自己的导出记录；核定人在独立运营页面停用旧设备；核对持有人后签发新的成员入口；新浏览器或工牌登记新公钥。旧浏览器使用新入口重新进入时会替换已停用的本地密钥。保留旧公钥以核验历史回执，但不恢复已丢失的私钥。

接口没有删除历史财务记录的按钮。成员可导出记录；个人信息更正、退出后的保留期限、匿名化与删除政策需由社区另行确定，不能用删除交易来取消已发生的交换。

## 试点前待完成

可信工牌和真实 NFC 实测、成员入会与恢复、角色凭证发放和轮换、正式数据保留规则、备份与故障恢复、可信授权签发及离线撤销策略，是下一阶段的实施事项。
